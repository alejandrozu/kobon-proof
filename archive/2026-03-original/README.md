# Superseded March 2026 repository

The six original repository files are preserved byte-for-byte from commit `fba9680` (22 March 2026). They are historical evidence, not part of the active Lake library.

`KobonTriangles.lean` contains **eight `sorry` placeholders**, including the central extension step and several input bounds. Its comments and the old paper's assertion that every result is fully formalized are not supported by this source. There may also be other compilation/proof defects in this draft. No newer completed public version was found during this audit.

The replacement checked development is in the root `Kobon/` directory. Read `FORMALIZATION.md` for what it actually proves. The original unrestricted recurrence has not been promoted to a checked geometric theorem. The old files' contact/metadata and claims are preserved as they were, and should not be reused as current publication metadata.
