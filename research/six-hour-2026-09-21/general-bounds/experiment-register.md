Python search code uses the standard library except numerical optimization and proposal generation, which use NumPy/SciPy. The session installed SciPy into an ignored host-local directory. This is an optimization runtime dependency, not a proof oracle; the independent certificate counters use only Python's standard library. Lean modules use the repository-pinned Lean and Mathlib versions.

The precise wall-clock durations, random seeds, LP status and proposal counts belong to their saved JSON reports. Where a script reports a floating score, it is not treated as an exact face count until reconstructed and independently recounted. No external email, issue or OEIS edit was sent during these audits.
